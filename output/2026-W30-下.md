### 🔮 新机爆料

#### 1. Minecraft: Java Edition 系统需求在支持 Vulkan 前有所提升
![配图](images/0bdb9c3dd47f.jpg)

《Minecraft: Java Edition》即将迎来基于 Vulkan 的大型渲染升级，Mojang 同步调整了游戏的最低和推荐系统需求。新需求主要提升了显卡和驱动版本门槛，以确保 Vulkan 渲染器稳定运行。部分老旧硬件将无法再流畅运行游戏，但换来了更好的性能与画质表现。Vulkan 升级是《Minecraft》Java 版近年最重大的技术更新，系统需求提升是合理代价。对 Steam Deck 用户而言，Vulkan 原生支持将显著改善游戏在 Linux 下的兼容性与帧率，是利好消息。（来源: GamingOnLinux）

### 🆕 新机发售

#### 1. NVIDIA、Red Hat、Cloudflare、The Linux Foundation 等联合发起“开放安全AI联盟”

NVIDIA、Red Hat、Cloudflare 与 Linux 基金会等多家行业巨头共同宣布成立“开放安全AI联盟”（Open Secure AI Alliance）。该联盟旨在通过共享开源工具，推动 AI 技术的负责任使用与信任建立。首批成果将包括安全基准测试工具和威胁模型库，面向开发者和企业开放。该联盟的成立标志着 AI 安全从单打独斗走向行业协作。对于 Linux 和 Steam Deck 生态而言，开源安全工具的普及将间接提升游戏平台的整体安全性，减少恶意软件风险。（来源: GamingOnLinux）

#### 2. Allogloom 是一款画面精美的点击式冒险游戏，将于10月发布

独立游戏《Allogloom》正式公布发售日期，将于2026年10月登陆 PC 及主流平台。这是一款手绘风格的点击式冒险游戏，以阴暗奇幻的世界观和细腻的像素美术著称。开发者表示游戏流程约8-10小时，支持 Steam Deck 原生运行，并已针对手柄操作进行优化。点击式冒险在 Steam Deck 上一直有稳定受众，《Allogloom》凭借出色的美术风格和原生支持，有望成为下半年该品类中的黑马。对掌机玩家来说，又多了一款值得期待的叙事佳作。（来源: GamingOnLinux）

### 📱 系统更新

#### 1. Wine 11.14 为 DirectSound、BCrypt、FreeBSD 带来改进

Wine 开发版 11.14 正式发布，本次更新重点改进了 DirectSound 音频后端、BCrypt 加密库以及 FreeBSD 平台兼容性。DirectSound 的优化将提升部分老 Windows 游戏在 Linux 下的音效表现，BCrypt 改进则有助于运行依赖现代加密协议的应用。此外，FreeBSD 支持也得到了持续完善。Wine 的每次迭代都在缩小 Linux 与 Windows 的兼容性差距。DirectSound 改进对 Steam Deck 上运行老游戏尤其重要，能减少音频卡顿和延迟问题，提升整体游戏体验。（来源: GamingOnLinux）

#### 2. GE-Proton 11-3 带来更好的 OptiScaler 集成、AMD FSR4 改进以及大量游戏修复

社区维护的兼容层 GE-Proton 11-3（以及此前发布的 11-2）是一次重大更新。新版本改进了 OptiScaler 集成，使第三方缩放方案更易用；同时针对 AMD FSR4 进行了优化，提升画质与性能平衡。此外还修复了包括《赛博朋克2077》《艾尔登法环》在内的多款游戏在 SteamOS 下的崩溃问题。GE-Proton 已成为 Steam Deck 玩家不可或缺的工具。本次更新对 FSR4 和 OptiScaler 的强化，意味着掌机玩家能以更高帧率、更好画质运行 AAA 大作，进一步拉近了掌机与桌面 PC 的游戏体验差距。（来源: GamingOnLinux）

#### 1. Valve在最新的Steam Beta中开始改进账户切换功能
![配图](images/0b7d57268c13.jpg)
